# 常微分方程 · 期中考互動學習站

**Ordinary Differential Equations — Interactive Midterm Study Site**

一個不用安裝、打開就能用的 ODE 期中考複習網站。涵蓋 **Basic Concepts → Separable → Exact → Linear → 二階齊次線性 → 常係數 → Euler–Cauchy → 存在與唯一性** 八個主題，中英對照、每題逐步詳解，並附上可以動手玩的互動實驗室、題庫與單字卡。

🔗 **線上版：[https://yuchen0614.github.io/ode-midterm-interactive/](https://yuchen0614.github.io/ode-midterm-interactive/)**

### 互動功能

- **38 題逐步詳解例題**（共 213 個推導步驟）—— 按「下一步」逐步展開，先自己想再看答案。
- **64 題題庫**：單選／是非／填數字三種題型，答完立刻給詳解；答錯自動進 **錯題本**，可以「只練錯題」。
- **32 張公式記憶卡**：翻卡複習，可標記已記住。
- **8 個互動實驗室**（見上表）：方向場可以用滑鼠點出積分曲線、拉桿即時改參數。
- **學習進度**：章節讀完打勾、進度環、分章測驗統計（存在瀏覽器本機，不上傳）。
- **全文搜尋**、**深／淺色主題**、**手機版**、**列印樣式**。

## 怎麼用（建議順序）

1. 讀一節 → 玩那一節的互動元件（有 🧪 標記的章節）。圖形會把公式變成直覺。
2. 每節的「**加強例題**」先在紙上做，再按「下一步」對答案。
3. 全部讀完做一次 **15 題測驗**；錯的進錯題本，隔天再練一次。
4. 考前 10 分鐘：翻 **公式記憶卡** + 掃 **附錄 D 清單**。

## 本機使用

不需要任何建置工具、不需要伺服器，**直接雙擊 `index.html` 就能跑**（所有 KaTeX 字型與程式都放在 `assets/` 內，離線可用）。

若想用本機伺服器：

```bash
# 任選一種，在專案根目錄執行
python -m http.server 8765      # 然後開 http://localhost:8765/
npx serve .
```

## 專案結構

```
index.html                  單頁入口（hash router）
assets/
  style.css                 設計系統（CSS 變數、深淺色、列印樣式）
  katex/                    本地 KaTeX 0.16.11（CSS + JS + 20 個 woff2 字型，離線可用）
js/
  app.js                    路由、導覽、搜尋索引、進度儀表板
  store.js                  localStorage 狀態（進度／測驗／錯題／記憶卡）
  render.js                 內容區塊渲染 + 逐步詳解元件
  plot.js                   迷你數學運算式編譯器 + Canvas 繪圖工具箱（方向場、RK4、等值線）
  widgets.js                實驗室：方向場、特徵根、彈簧阻尼、Euler 對照
  widgets2.js               實驗室：正合檢測、Wronskian、積分因子、存在唯一
  quiz.js                   題庫引擎（含錯題本）
  cards.js                  記憶卡引擎
  data/
    core.js                 主內容（§0–§8 + 附錄 A–D）
    extra.js                38 題加強例題（逐步詳解）
    quiz.js                 64 題題庫
    cards.js                32 張記憶卡
```

### 技術重點

- **零依賴、零建置**：純 HTML/CSS/JS（classic script，非 ES module），因此 `file://` 直接開也能動。
- **數學運算式是自己寫的解析器**（`plot.js` 裡約 120 行 recursive descent），不是 `eval`，
  支援 `+ - * / ^`、括號、隱式乘法（`2x`、`3sin(x)`）、`sin cos tan exp ln sqrt abs ...`，所以
  「正合性檢測器」與「存在唯一性檢驗器」可以吃使用者輸入的任意 `f(x, y)` 並用數值方法檢驗。
- **繪圖**：方向場、RK4 積分解曲線、marching squares 等值線，全部在 Canvas 上手寫。
- **KaTeX 本地化**：連 `fonts/` 都放進專案，離線也不破圖。
